# Dương Tuyết AI Store

Website tĩnh bán Skill ChatGPT, ứng dụng AI và Ebook. Có thể triển khai trực tiếp trên GitHub Pages hoặc Vercel.

## Cập nhật thông tin thật

Thông tin Dương Tuyết đã được điền sẵn trong `config.js`. Khi cần thay đổi, sửa 5 trường trong `STORE_CONFIG`:

- `zaloPhone`: số Zalo, chỉ nhập số.
- `email`: email nhận hỗ trợ.
- `bankName`: tên ngân hàng.
- `bankAccount`: số tài khoản.
- `bankOwner`: tên chủ tài khoản.

## Cập nhật sản phẩm

Danh sách nằm trong `STORE_PRODUCTS` ở `config.js`. Mỗi sản phẩm gồm tên, mô tả, giá, nhóm và trạng thái mở bán.

## Chạy thử

Mở `index.html` trực tiếp hoặc chạy một static server. Không cần cài thư viện.
